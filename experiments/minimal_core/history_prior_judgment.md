# 历史任务能否学出可迁移的结构偏好

实验编号：`history-prior-enumeration-v1`  
日期：2026-09-10

## A. 最小模型与信息预算

本轮明确假设候选任务只有两个已知函数：

    A(u) = u0 XOR u2
    B(u) = u0 XOR u1 XOR u2 XOR u3

任务B的总体比例epsilon未知，单个任务的身份也未知。每个历史任务独立抽取类型，只提供一条均匀随机的四比特输入及其正确标签；不提供任务身份。

两函数在8种输入上相同、8种输入上不同。因此一条历史观测以1/2概率识别该任务的类型，其余情况不提供类型信息。

记a、b为被识别为A、B的历史任务数。采用固定的Beta(1,1)先验：

    epsilon | history ~ Beta(1+b, 1+a)
    P(next task is B | history) = (1+b)/(2+a+b)

元记忆为两个整数计数(a,b)。这是额外的跨任务数据和状态资源；本轮不是固定一比特架构比较。候选函数已知的假设也比上一轮256规则搜索更强，不能跨协议比较错误率并称为架构增益。

新测试任务与历史任务独立。学习器没有访问测试总体比例或测试标签来挑选先验。

## B. 精确评价与基线

决策使用后验多数，平票公平随机。比较：

- 从独立历史更新的先验。
- 固定均衡先验，相当于不从历史获得类型偏好。
- 固定偏好A。
- 知道测试总体比例的oracle基线，仅作为不可突破的参考，不是可用算法。

后验多数决策与普通经验频数多数决策相同。这里没有显示分阶段架构相对普通统计计数的优势。

主表不给新任务任何标注，按16种均匀输入评价。另计算新任务提供n条不同校准样本、只在剩余输入上评价的情况。

历史计数服从三项分布，单任务结果概率为：

    P(identified A) = (1-epsilon_history)/2
    P(identified B) = epsilon_history/2
    P(uninformative) = 1/2

计算枚举所有计数组合及其精确权重，不进行随机模拟。

## C. 稳定分布中的收益

设历史和测试都使用epsilon=0.1：

| 历史任务数K（每个提供一条标注） | 新任务平均错误率 |
|---:|---:|
| 0 | 25.0000% |
| 1 | 17.0000% |
| 2 | 13.0000% |
| 4 | 9.1000% |
| 8 | 6.3081% |
| 16 | 5.1662% |
| 32 | 5.0035% |
| 64 | 5.0000% |

知道真实总体比例的oracle错误率为5%，因为新任务仍有10%概率属于少数类型，而两函数仅在一半输入上不同。无限历史也不能代替识别当前任务所需的证据。

固定偏好A在这一特定总体中已达到5%，历史学习并不优于这个恰好匹配环境的固定偏好。若epsilon=0.9，固定偏好A的错误率为45%，历史学习则对称地趋近5%。若epsilon=0.5，任意历史数量下的平均错误率都是25%，没有稳定多数可学。

因此，收益是减少对未知任务分布的错误偏好，不能表述为对任何固定先验都具有优势。

## D. 历史失效时的反例

保持历史epsilon_history=0.1，但新任务来自epsilon_test=0.9。学习器仍使用原来的跨任务分布稳定假设：

| 历史任务数K | 保留历史的平均错误率 |
|---:|---:|
| 0 | 25.0000% |
| 4 | 40.9000% |
| 8 | 43.6919% |
| 16 | 44.8338% |
| 32 | 44.9965% |
| 64 | 45.0000% |

忽略历史、回到均衡先验的错误率仍为25%；知道新总体比例的oracle为5%。更多历史使该固定学习器更确信过时的偏好。

被否定的是分布稳定假设下持续累积的适用性，不是“记忆作为资源有害”。拥有更多信息的最优决策者可以选择忽略它；本实验的错误来自使用了失效的模型假设。

如果当前任务提供一条能区分A与B的正确标注，就能确定其身份，旧偏好不再决定答案。这依赖无噪声和候选函数完备的假设。随机的一条标注只有1/2概率具有这种诊断能力。

## E. 可复核关系与边界

设历史后选择A、选择B和平票的概率分别为p_A、p_B、p_T。新任务没有校准样本时：

    R = (1/2) * [epsilon_test*p_A + (1-epsilon_test)*p_B + (1/2)*p_T]

如果先给新任务n条不同校准样本，n<=8时，只要有诊断样本即可确定类型，因此：

    R_n = [C(8,n)/C(16,n)] * [8/(16-n)]
          * [epsilon_test*p_A + (1-epsilon_test)*p_B + (1/2)*p_T]

n>=9且仍有未见输入时，必然含有诊断样本，错误率为0。

验证包含：

- 小规模历史观测路径枚举与三项计数公式一致。
- n=0、1、2、4的新任务校准子集与测试输入直接枚举，与公式一致。
- 学习风险不低于已知测试总体比例的oracle。
- 平衡总体没有历史平均收益。

该更新只依赖(a,b)，任意重排历史都得到相同后验。历史更新可以写成普通的可交换计数递归，不要求周期，更没有展示信息螺旋独有结构。

本轮没有检验含噪声观测、未知任务函数、自动变化检测、神经网络训练或IST实现。

# 周期记忆优势的有限状态审计

实验编号：`phase-memory-enumeration-v1`  
日期：2026-09-10  
方法：完整穷举，无训练、随机采样或外部依赖。信息量的对数使用浮点计算；联合频数是精确整数。

## A. 最小模型与待检验命题

四个输入位 u0、u1、u2、u3 独立且等概率。目标 Z = u0 XOR u2；u1、u3 是干扰。阶段交替为“相关、干扰、相关、干扰”。

周期方案使用一比特内容记忆 m 和二阶段控制 j：

    m0 = 0, j0 = 0
    m_next = m XOR ((1-j) AND u)
    j_next = 1-j

末态记忆恰好等于 Z。普通一比特递归对照为 m_next = f(m,u)，要求 f 在所有时刻相同，且不能访问阶段、步数或中间输出反馈。

两者表面上都有一比特“内容记忆”，但前者额外使用了一比特阶段状态或等价的外部阶段信息。不能据此称两者资源和信息条件相同。

本实验只隔离周期/阶段的贡献，不要求状态单调增长，也不把这个有限状态系统称为完整的“信息螺旋”。

## B. 完整穷举结果

全部16种输入历史等概率。初态为0；每个候选使用其最优末态解码器。不存在训练与测试混用：这里直接计算已指定有限概率空间中的互信息和最优正确率。

| 模型类 | 穷举规则数 | 最大 I(Z;M) | 最大正确率 |
|---|---:|---:|---:|
| 一比特、无阶段信息、固定递推 f(m,u) | 16 | 0.065507845017 bit | 9/16 = 56.25% |
| 一比特内容记忆、两个阶段各自的递推 | 256 | 1 bit | 100% |
| 普通四状态固定递推，无外部阶段输入 | 65,536 | 1 bit | 100% |

规则计数分别为 2^(2*2)、16^2、4^(4*2)。第一类互信息最大值还等于：

    1 - (15/16) * h2(8/15)

其中 h2 为二元熵函数。最简单的最大值实现之一是 OR 累计：全零历史提供少量关于目标的证据。

这些最优值仅针对明示的确定性模型类；未枚举随机转移、时变无阶段对照或其他任务。

## C. 阶段优势如何被普通递归复现

把状态编码为 s = 2*j + m，则普通四状态函数直接实现同一过程：

    (0, u=0) -> 2; (0, u=1) -> 3
    (1, u=0) -> 3; (1, u=1) -> 2
    (2, u=0) -> 0; (2, u=1) -> 0
    (3, u=0) -> 1; (3, u=1) -> 1

脚本验证了所有16种输入的每一步状态对应，而不只是最终正确率。末态读取 s mod 2 即可得到答案。

这也是一般事实：周期模型 (j,m) -> ((j+1) mod p, F_j(m,u)) 已经是普通状态递推。若内容状态有 K 种，扩展状态至多 p*K 种。周期方案使用外部时钟时，公平对照也必须能访问同一时钟；否则应把时钟计入动态状态预算。

这里匹配的是动态状态容量与可用阶段信息。完整编译可保持原更新运算；本次没有比较训练效率、硬件延迟或所有可能的参数编码成本。

## D. 打破周期后的反例

给每条观测保留角色位 c：相关为1，干扰为0。采用普通递推：

    m_next = m XOR (c AND u)

将两条相关观测和两条干扰观测按全部六种合法角色顺序排列：

    0011, 0101, 0110, 1001, 1010, 1100

全部得到 I(Z;M)=1 bit、正确率100%。目标始终是两条相关观测的 XOR，重排不改变事实的角色和查询语义。一般地，该递推对任意角色顺序都累计所有相关位的 XOR。

因此，此任务中有效的是“知道哪些输入相关并选择性更新”。固定交替周期只是传递角色信息的一种方式，并非必要条件。

## E. 失败条件、信息对象和边界

若命题是“此周期方案在相同可用信息和总状态容量下，具有普通递归无法复现的优势”，则上面的完整状态编译已给出反例。

若命题是“正确保存该目标必须有固定周期”，则合法非周期角色顺序上的满分结果已给出反例。

若命题仅是“具有阶段信息的一比特模型优于不具有阶段信息的一比特固定递推”，则本次穷举支持它，但这是不同信息条件下的有限模型类比较。

信息对象也决定结论：

| 已处理输入数 | 关于第一个输入位的信息 | 关于最终目标 Z 的信息 |
|---:|---:|---:|
| 0 | 0 bit | 0 bit |
| 1 | 1 bit | 0 bit |
| 2 | 1 bit | 0 bit |
| 3 | 0 bit | 1 bit |
| 4 | 0 bit | 1 bit |

计算目标所需的信息增加时，单个旧事实的信息反而消失。因此，完整继承全部历史、保留任务信息和状态单调增长是不同要求。

本结果不否定所有周期驱动的实际效用，也不否定有限训练预算下的架构归纳偏置。它没有检验IST实现，更没有验证或反驳跨领域普适主张。

## F. 下一项最小问题

在双方都获得同样的阶段/角色信息，并限制相同有效状态容量后，一个具体的周期更新机制是否仍能在预先固定的任务上超过明确的普通递归基线？

若比较“所有同容量普通递归”，周期模型本身已包含在对照类中，不能主张超出该类最优值。合理的后续问题应限定为具体机制的样本效率、优化难度或资源成本，并事先规定最低效应和失败阈值。

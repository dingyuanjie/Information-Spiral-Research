# 结构假设的收益与失配边界

实验编号：`misspecification-enumeration-v1`  
日期：2026-09-10

## A. 最小任务分布

每个学习任务开始时，只选择一次目标函数：

- 概率 1-epsilon：Z=u0 XOR u2，第二阶段输入可以忽略。
- 概率 epsilon：Z=u0 XOR u1 XOR u2 XOR u3，第二阶段输入不能忽略。

一个任务内部的训练和测试始终使用同一个目标函数；任务身份不提供给学习器。epsilon表示不同任务之间的失配比例，不是标签噪声率，也不是任务内部发生概念漂移。

保持四比特均匀输入、一比特内容记忆、共同的外部阶段信息和固定末态读出。继续使用256个一般更新规则H，其中16个规则组成子集S，强制第二阶段不更新记忆。

训练集为16种输入中的n条不同样本；穷举所有训练子集，只在未见输入上评价。

## B. 硬约束与软先验

先验定义为：

    pi_lambda(h) = (1-lambda)/256 + lambda * 1[h in S]/16

比较预先列出的lambda=0、0.5、0.9、1：

- lambda=0：对一般规则均匀分配概率。
- 0<lambda<1：偏好S，但所有一般规则仍有正概率。
- lambda=1：只允许S，是硬约束。

学习规则为精确的一致性后验和加权多数预测，平票公平随机。两个任务都属于H，因此lambda<1时后验不会为空。

硬约束可能与全部训练标签不相容。此时明确记录“后验为空”，并以额外指定的公平猜测策略计入1/2损失。该猜测不是贝叶斯后验推断，也不删除失败任务。

## C. 收益何时被失配代价抵消

令a_G、a_H分别为一般均匀先验、硬约束在相容任务上的平均未见错误率；b_G、b_H为其在失配任务上的错误率。

总体风险：

    R_G(epsilon) = (1-epsilon)*a_G + epsilon*b_G
    R_H(epsilon) = (1-epsilon)*a_H + epsilon*b_H

当相容收益B=a_G-a_H>0、失配代价C=b_H-b_G>0时，硬约束仅在以下条件下更好：

    epsilon < epsilon_star = B / (B+C)

本协议下的精确穷举边界：

| 不同训练样本数n | epsilon_star |
|---:|---:|
| 4 | 48.7664% |
| 5 | 27.8926% |
| 7 | 3.7971% |
| 8 | 0.8196% |
| 10 | 0% |

样本增加后，一般模型在相容任务上的误差下降，硬约束原本的收益缩小；无法表示失配任务的代价仍然存在。n=10时两者在相容任务上均无未见错误，但硬约束在失配任务上全部拒绝并猜测，故任意正失配比例都会使它更差。

这些边界只适用于明示的任务分布、先验、学习器和拒绝损失策略，不是跨领域常数。

## D. 软先验对照

取n=7、epsilon=10%，混合任务上的平均未见错误率为：

| 先验 | 平均错误率 |
|---|---:|
| 一般均匀先验lambda=0 | 2.0297% |
| 软先验lambda=0.5 | 0.4048% |
| 软先验lambda=0.9 | 0.3489% |
| 硬约束lambda=1 | 5.1364% |

硬约束在失配任务中有99.3706%的训练子集导致后验为空。软先验能在S被数据全部排除后继续使用H中的其他规则。

这里不声称lambda=0.9最优，也不声称它在其他任务分布中总是更好。这些强度是用于比较的固定选项，并未通过独立验证集选择。

这属于普通贝叶斯模型比较：结构假设保留非零的替代解释时，可以被数据修正。它不是信息螺旋特有机制。

## E. 失败、成本与验证边界

硬约束的失配错误率可能略大于50%，因为未被训练数据排除的少数规则，在剩余未见样本上可能系统性错误；后验为空的任务则按预先声明的策略猜测。不能把总体结果简单替换成“每个训练集都恰好50%”。

如果拒绝的成本改为kappa，失配风险应改为：

    b_H(kappa) = nonempty_error_contribution + rejection_probability*kappa

阈值必须相应重算。如果拒绝不计成本，就应同时报告预测覆盖率，不能把不作答误报为高准确率。

已验证：

- 相容任务的两个端点先验逐项复现上一轮结果。
- 软先验在两个任务的所有训练子集上均有非空后验。
- 失配任务的完整16条数据会排除全部S。
- 用独立JavaScript数组实现复核n=4时两种任务、三种先验的错误率和拒绝率，与Python位集合实现一致。

软先验只能在H内部修正假设。如果真实任务也不属于H，一般模型同样可能全部被数据排除。本轮没有检验任务内部变化、神经网络训练或永久状态累积，也没有验证IST代码。

## F. 下一项最小问题

能否从独立的历史任务中估计结构偏好的强度，再在完全未参与调参的新任务上获得收益？

应先固定任务族、历史任务数量、失败成本和评价协议，再比较固定先验与可更新先验。否则，知道失配比例后挑一个表现最好的lambda，只是事后选择。
